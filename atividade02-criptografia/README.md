Sobre o Projeto
Programa desenvolvido em linguagem C que implementa um sistema de criptografia em dupla camada, unindo a tradicional Cifra de César a conceitos de matemática aplicada.

O que o Código Faz
1. Entrada: Recebe uma palavra secreta e um valor de `SHIFT` definido pelo utilizador.
2. Dupla Criptografia: Aplica o deslocamento fixo da Cifra de César somado a um deslocamento dinâmico baseado na Sequência de Fibonacci.
3. Processamento: Utiliza um vetor de alfabeto explícito e o operador módulo para garantir que as letras dão a volta corretamente.
4. Registo Automático: Exibe o resultado no terminal e gera um ficheiro de log chamado `resultado_criptografia.txt`.
